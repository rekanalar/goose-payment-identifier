# goose-payment-identifier

Payment identifiers for Goose: IBAN, BIC, ABA routing number, ISO 11649 creditor reference, payment card numbers, ISO 7064 and Luhn.

## Install

Add this to the root file of the program that uses it:

```goose
import goose_payment_identifier from "rekanalar/goose-payment-identifier@v1";
```
